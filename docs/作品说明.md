# 作品说明（赛题三：AI 开票 Agent 离线轨迹评测）

> 单文件版：把"作品是什么、怎么判、凭什么可信、怎么复现"压在一页里。
> 更细的材料见 `README.md`、`docs/method.md`、`docs/architecture.md`、`docs/g6-*.md`。
> **数据性质**：官方数据为合成沙箱数据；本作品在公开训练集上报告的指标是**拟合值**，
> 变形实验与依据记录演示使用**自造样本**，均**不代表隐藏集泛化能力**。

## 一、一句话

给 AI 开票 Agent 的离线轨迹做**可复核的版本评测**：判断每条运行是否按题内规则处理正确、
发票是否真的生成、最早错在哪一步、错误如何传播，以及两个版本到底谁更好、好在哪里。

## 二、解决什么问题

只看成功率无法回答"新版本是变强还是变弱、哪个能力退化、错在哪个事件"。
本作品把评测拆成四层，每层都可单独验证：

| 层 | 做什么 | 落地位置 |
|---|---|---|
| 契约层 | 把不同 JSON 结构规整成统一 Trace IR（事件/工具调用/快照） | `tracelab/contracts.py`、`adapters.py` |
| 状态层 | 从轨迹重建业务状态（金额、口径、确认、提交、终态） | `tracelab/state.py` |
| 规则层 | 16 条确定性规则（含 1 条"拒判"规则），三态判定 | `tracelab/rules.py` |
| 归因层 | 首因、传播、抑制（工具正常拦截 vs Agent 绕过）、质量分 | `tracelab/attribution.py` |

## 三、怎么判（评分口径）

- **三态**：`PASS` / `FAIL` / `UNKNOWN`（证据不足）。UNKNOWN **不进**准确率分母，也不参与版本排名。
- **处理正确性**与**发票是否生成**分别输出（对应赛题要求的两件事）。
- **扣分**：每条规则有维度与分值；违规扣分，质量分 = 100 − 扣分。
- **传播抑制**：上游首因成立后，下游由它导致的问题不再重复扣分（避免"一次错误罚多次"）。
- **工具拦截不是故障**：工具以保护性错误码拒绝，满足保护规则；只有 Agent 绕过才算违规。
- **不用大模型裁决**：所有结论由确定性规则 + 轨迹证据得出，因此可复现、可复核、可现场演示。
  模型只在复赛阶段按赛事要求接入，且不得覆盖确定性结论（见 `docs/method.md` §2）。

## 四、凭什么可信（四个可独立复核的证据）

| 证据 | 数字 |
|---|---|
| 官方参考标注上的方法指标（**公开训练集，拟合值**） | 六项指标 1.0000（根因标签 Macro-F1 / 证据编号有效性等） |
| 回归闭环：三态快照复测 | 28 / 28 快照零漂移（退出码 0） |
| 变形实验：语义保持（改名/改序/改金额写法/加无关元数据…） | **42 / 42 一致**（含 1 个"应拒判"样本） |
| 变形实验：业务语义变化（16 条规则） | **18 / 18 检出**、首因 **18/18**、误报 **0/18** |
| 依据记录独立复核（开票 8 条 + 报销 4 条规则） | 记录全部 `VERIFIED`；篡改/版本不符 → `MISMATCH` |
| 拒判稳定性（无业务阶段 / 无采集 / 采集无字段） | **3 / 3** 稳定判 `UNKNOWN`，预期外 UNKNOWN **0** |

## 五、怎么复现（不需要官方资料包的那条最关键）

```bash
# ① 批量评测（需要官方资料包）：产出 submission.jsonl / results.json / 四份报告
python -m tracelab evaluate --cases data/official/student-1.0/02_公开训练轨迹.jsonl \
  --labels data/official/student-1.0/03_公开训练参考标注.jsonl --out out/train

# ② 回归闭环复测（0 漂移 = 退出码 0）
python -m tracelab regression verify --pack regression/invoice-pack/regression-pack.json \
  --cases data/official/student-1.0/02_公开训练轨迹.jsonl --out out/regression-verify

# ③ 变形实验（**不需要资料包**，固定种子，两次运行逐字节一致）
python -m tracelab experiments --out out/experiments
#   → report.md（人读）+ report.json（机读：分子/分母、覆盖规则、样本摘要）

# ④ 依据记录 + 独立检查器（自造样本）
python -m tracelab evidence --cases <self-made.jsonl> --out out/evidence

# ⑤ 提交包自检（生成提交包 + 逐项检查清单）
python scripts/build_submission_bundle.py --out dist
```

环境：Python 3.11+，**零第三方运行时依赖**，纯离线，无数据库/无网络/无模型调用。

## 六、加分项覆盖（不夸大）

| 加分项 | 状态 |

| 评测发现沉淀为可复用 Case，支持持续回归（评测—归因—优化—复测闭环） | 已实现：三态快照 + 复测 + 覆盖前归档 |

## 七、边界（请和结论一起读）

1. 数据为**合成沙箱**；公开训练集六项指标 100% 是**拟合值**，不是泛化能力。
2. 变形实验与依据记录演示的样本**全部自造**，结论只对这批构造成立。
3. 报销规则包是**自造原型**，不接真实财务系统，不代表真实报销合规能力。
4. 未使用大模型做裁决；若复赛引入，确定性结论仍不得被覆盖。
5. 主办方资料包不随作品分发（符合"非公开赛事资料仅限本次赛事使用"的要求）。
