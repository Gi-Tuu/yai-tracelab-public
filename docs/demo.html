这个页面说明的评测原则

  • 三态判定：PASS / FAIL / UNKNOWN，UNKNOWN 不进准确率分母，也不被当作"Agent 做错"。
  • 证据可复核：每条根因都带规则 ID、首因事件、证据事件编号，可回原始轨迹逐条核对。
  • 首因 vs 传播：只在参数真的流动到下游时建立传播边，不按时间先后推因果。
  • 工具拦截不是故障：保护性拒绝单独记录为 guard，归因落在 Agent 侧。
  • 版本比较：同 Case 双版本按内部三态与质量分比较；证据不足时拒判而不是硬判。

本页不含时间戳与耗时，便于归档与比对。完整方法见 docs/method.md。
