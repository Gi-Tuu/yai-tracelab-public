TraceLab 复赛验收集与证据机制说明

对应 `tracelab` 5 阶段确定性流水线

公开测试冻结集

FREEZE

将脱敏后的开票与 AI 顾问真实业务轨迹锁定为不可变输入，防止调参过拟合，确保跨版本评测口径一致。

  • 包含金额口径、确认前置、空轨迹拒判等核心边界
  • 所有运行记录与结果哈希绑定，支持独立复现
RECEIPTS

逐调用收据链（Schema v2）

对每一步工具调用和模型裁决生成可校验回执，支持断点续跑与 `verify_receipts.py` 离线验真。

  • 自动区分正常安全拦截与真实业务违规
  • 防止下游连锁报错掩盖真正的首因事件
CONTROLS

专项反事实与注入对照

内置等义改写、提示词注入、证据缺失、反事实扰动与错配对照 6 类探针，验证评测器自身抗干扰能力。

  • 独立留出集消融对比验证
  • 4/8 并发长时间浸泡压测稳定通过
DUAL TRACK

初赛双轨格式兼容

通过统一 Trace IR 适配器向下兼容初赛日志格式，同时支持一键导出 7 章节正式评审报告模板。

  • 开票场景与 7 域 AI 顾问场景共用同一归因内核
  • 支持 `python -m tracelab demo` 单文件归档

Agent 与专属 Judge

两类业务、独立标准、版本与证据边界
INVOICE / JUDGE

开票 Agent 的专属 Judge

业务类型 invoice。Judge 使用开票 addendum，区分任务处理正确性与实际出票；等待、阻断、取消、转人工可 PASS。

  • Judge：qwen3.8-max-final-round · prompt v1
  • 规则集：rulepack-1.3 · 16 条确定性规则
  • 证据：首错、root_causes、事件引用必须属于当前 run
AI CONSULTANT / JUDGE

AI 顾问 Agent 的专属 Judge

业务类型 ai_consultant。使用 AI 顾问 addendum，覆盖工资个税、银行流水、增值税票税、税款缴纳、社保、完税通知、邮寄资料七域及跨域。

  • 标准：依据性、用户限制、不确定性、任务完整性、安全边界
  • 结论必须引用轨迹或资料证据，不能只按关键词/流畅度
  • 与开票 Judge 分开判定、分开结果归属，不静默混用
DATA / VERSION

数据、版本与治理

数据集按用途分区：开发调优集、公开独立测试集、未标注验证集、专项验收集；冻结后不按公开反馈调 Prompt。

  • freeze-public-v1.json：模型、参数、Prompt、数据哈希
  • receipts：每次 Judge 调用的输入、模型、Prompt、耗时与链哈希
  • 版本：evaluator / rulepack / prompt / config / dataset 均可追溯
RELIABILITY

可靠性、四态与拒判

PASS / FAIL / REJECT / NO_RESULT 四态；证据不足不硬填布尔。断点身份包含输入、Judge、模型、Prompt、规则和配置。

  • Judge 超时/异常 → NO_RESULT，不伪造成 PASS
  • 任务中断后从 checkpoint 恢复，已完成 run 不重复调用
  • 所有结果、收据和统计可从任务目录追溯
